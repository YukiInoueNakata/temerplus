## 画面と表示

- **画面の言語**: 日本語と英語を切り替えられます（右上の「日本語 / English」、起動時の案内の「日本語｜English」）。選んだ言語はブラウザに残ります。図の中の文字（凡例など）の言語は、図ごとに設定の「図の言語」で決めます。
- **横型と縦型**: 時間が右へ流れる横型と、下へ流れる縦型を、右上の「横型」「縦型」で切り替えられます。Box・矢印・SD/SG・凡例は向きに合わせて置き直されます。
- **パネル**: 左のデータシート（表の形で編集）、右のプロパティ（選んだ要素の細かな設定）、コメントの欄を、出したり隠したりできます（表示 > パネル）。
- **表示の補助**: グリッド、接続点、スナップ、用紙の枠、上と左のルーラー、タイプラベル（BFP などの種類の文字）、SD/SG の帯（表示）。
- **画面に合わせる**: 全体・横幅・縦幅を画面に合わせます（表示 > フィット、図の右下のボタン）。ズームの倍率は下のステータスバーに出ます。
- **コマンドパレット**: Ctrl+K（Mac では ⌘K）で、機能の名前を入れて呼び出せます。
- **起動時の案内**: 起動すると「TEMer へようこそ」が開き、新しく作る・開く・デモを開くを選べます（ヘルプ > 起動ウィザードでいつでも開けます）。

## TEM 図の要素

- **Box の種類**: 行為、潜在的な行為（2026-11-12 に 通常・潜在経験 から改称）、分岐点（BFP）、等至点（EFP）、両極化した等至点（P-EFP）、必須通過点（OPP）、セカンド等至点（2nd EFP）、両極化したセカンド等至点（P-2nd EFP）、その他（挿入 > Box）。
- **径路（Line）**: 実現した径路の実線径路と、実現しなかった径路の点線径路。選んだ Box を順につなぐこともできます（挿入 > 矢印）。直線と曲線を選べます。
- **SD・SG**: 社会的方向づけ（SD）と社会的助勢（SG）。Box や矢印に付ける、2 つの Box の間に置く、図の上下の帯にまとめて置く、の 3 つの置き方があります（挿入 > SD/SG 作成・SD/SG 配置）。
- **時期ラベル**: 時期の区切りと名前（挿入 > 時期ラベル）。
- **非可逆的時間**: 時間の矢印は図の外側に自動で引かれ、SD/SG や文字に重ならない位置に置かれます。
- **凡例**: 図で使った記号から自動で作ります。新しい図では、時間の矢印の下に、横型なら左端を矢印の始まりにそろえて横長に自動で置きます（動かすと手動になります）。項目・列の数・文字の大きさ・枠を変えられます。
- **メモと記号**: 図の上に置くメモと、引き出し線つきの記号（挿入 > メモ・記号）。
- **ラベル**: Box や SD/SG に、種類の文字（BFP-1 など）とサブラベル（補足の文）を付けられます。Box の文字は太字・下線・色などで飾れます。
- **シート**: 1 つのファイルに複数の図（シート）を持てます。協力者ごとの図や、まとめた図を並べて置けます。

## 編集

- **操作のモード**: 移動（画面を動かす。キー H）・選択（図形を動かす。キー V）・範囲選択（キー M）（編集 > モード）。Box・メモ・記号などの図形は「選択」のモードでつかんで動かします。
- **Box の手直し**: Box を右クリックすると、種別・Item レベルの上げ下げ・文字の編集・削除のメニューが出ます。Box を選ぶと上に小さなツールバーが出て、種別と Item レベルの上げ下げができます。数字のキー 1〜7 で種別（1 行為・2 分岐点・3 等至点・4 両極化した等至点・5 必須通過点・6 潜在経験・7 その他）、矢印のキーで位置（Shift と一緒なら 1 レベル）を変えられます。複数を選んでいれば、まとめて変わります。矢印のキーで動かせるのは「選択」「範囲選択」のモードのときです。
- **基本の操作**: 元に戻す・やり直し、コピー・貼り付け・複製・削除、すべて選ぶ（編集）。
- **大きさ**: 文字に合わせて Box の幅・高さを決める（編集 > 文字に合わせる）。幅・高さ・大きさ・文字の大きさをそろえる（整理）。
- **並べる**: 左・中央・右、上・中央・下にそろえる、横に等しい間隔で並べる（整理 > 整列）。前面・背面（整理 > 順序）。
- **入れ替えとずらし**: Box の順序の入れ替え、ある Box より後ろをまとめてずらす（編集）、2 つの Box の間に Box を入れる（挿入 > 間に挿入）、図全体の大きさを変える・動かす（ファイル > リサイズ・移動）。
- **重なりチェック**: Box・文字・SD/SG・凡例などの重なりや、枠からはみ出した文字を一覧にし、その場所へ飛べます（整理 > 点検 > 重なりチェック）。
- **データシート**: 図を表の形で見て、文字・種類・位置を編集できます。行のコピーと貼り付けもできます。

## 見た目の設定

設定（ファイル > 設定）で、図の見た目を細かく決められます。

- **全体**: 図の言語、横型・縦型、文字の大きさなど。
- **スナップ**: 置くときに吸い付く間隔。
- **Box スタイル**: 種類ごとの枠・線・色。用意されたテーマ（線の種類を実在性だけに使う簡素化方式、カタログTEA 図 2-1 の描き分けを含む）を選べ、自分のテーマを保存できます。
- **Line（矢印）**: 線の太さ・色・矢じり。
- **タイプラベル**: BFP などの種類の文字を出すか、その書き方。
- **非可逆的時間**: 矢印の文字・長さ・位置・太さ。
- **時期区分**: 時期ラベルの位置と書き方。
- **凡例**: 凡例に入れる項目と見た目。
- **SD/SG 配置**: 上下の帯の有無・高さ・位置、帯の中の並べ方。
- **プロジェクト**: 図の題・作者などの情報と、新しく作る要素の既定値。

## 取り込み

- **表から取り込む**: CSV・Excel のファイルから Box・矢印・SD/SG・時期を作ります。MAXQDA のコード付きセグメントの書き出しも読めます（ファイル > 表から取り込み）。
- **PowerPoint から取り込む**: PowerPoint（.pptx）で描いた TEM 図を読み、図形の役割を推測して TEMer Plus の図にします。推測は取り込む前に確かめて直せます。
- **別シートとして開く**: ほかの .tem ファイルの図を、今のファイルのシートとして足します。

## 原文（逐語録）と協力者

- **原文の取り込み**: インタビューの逐語録（テキスト・Word・表）を 1 つずつ、またはまとめて取り込みます（ファイル > 原文・原文一括）。
- **原文ビューア**: 逐語録を読みながら、段落から Box を作ったり、Box と段落を結んだり（原文参照）できます。検索、まとめて結ぶ、Box から元の段落へ飛ぶ、もできます。
- **切片化から Box 化へ**: 原文で範囲を選んで「切片にする」と、切片として残ります（原文の上では紫の破線の下線）。「切片の一覧」では切片が原文の順に並び、見出し（Box の文字）・種別・Item レベル・メモを書けます。選んだ切片から Box を作ると、原文の順に時間の方向へ並びます。一覧で見出しや種別を変えると、作った Box にも反映されます。「Box を原文の順に並べる」で、Box を原文の順に並べ直せます。
- **協力者**: 研究に招いた人（協力者）ごとに逐語録と図をまとめ、仮名で表せます。
- **匿名化して書き出す**: 名前などを仮名に置き換えたファイルを書き出せます。

## 出力

- **形式**: PNG（画像・約 300dpi）、SVG、PDF、PPTX（PowerPoint で編集できる図形）、プリンターでの印刷（ファイル > 出力）。
- **用紙と収め方**: 用紙の大きさ・向き・余白を決め、1 枚に収める、または Box の間で区切って複数ページに分けて出力できます。
- **含める要素の確認**: 凡例・時期ラベルなどを出力に含めるかを、出力の前に確かめます。
- **紙面での読みやすさ**: 用紙に収めたときにいちばん小さい文字の大きさ（pt）を示し、7 pt 未満なら知らせます。プレビューをグレースケールで見て、白黒の印刷で見分けられるかを確かめられます。
- **プリセット**: よく使う出力の設定を名前を付けて残せます。
- **論文用のレポート（Word）**: 記号体系の宣言・表記方針・図・各要素の説明をまとめた Word のファイルを作ります（ファイル > 論文レポート）。本文は図の言語で書かれます。
- **CSV の書き出し**: 図の要素を CSV に書き出します（ファイル > CSV エクスポート）。

## ファイルと保存

- **.tem ファイル**: 図は .tem（JSON）のファイルに保存します。Chrome と Edge では同じファイルに上書きで保存できます。
- **自動の控え**: 保存していない変更はブラウザの中に自動で残り、次に開いたときに戻せます。
- **インストール不要**: ブラウザで開くだけで使えます。図のデータはお使いの PC の中だけで扱い、サーバーには送りません。
